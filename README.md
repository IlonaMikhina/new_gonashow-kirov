# ГОУ НА ШОУ — сайт

Многостраничный адаптивный сайт для команды «ГОУ НА ШОУ» (Киров и Кировская область).

## Как открыть
Просто откройте файл `index.html` в браузере. Сборка не требуется.
Для корректной работы локально можно запустить простой HTTP-сервер:
```
python -m http.server 8000
```
и открыть http://localhost:8000

## Структура
- index.html — главная
- shows.html — каталог шоу
- complex.html — комплексные программы
- schools.html — для детских садов и школ
- partners.html — партнёрам
- about.html — о нас
- contacts.html — контакты и форма заявки
- assets/style.css — все стили (дизайн-система)
- assets/data.js — контент, цены, изображения и контакты
- assets/app.js — логика и рендеринг
- robots.txt, sitemap.xml — для SEO

## Где редактировать
Все тексты, цены, фото и контакты собраны в одном месте — файл `assets/data.js`:

1. Контакты — объект CONTACTS. Замените заглушки на реальные данные:
   - phone — телефон, который видит посетитель
   - whatsapp — ссылка вида https://wa.me/79XXXXXXXXX
   - telegram — ссылка вида https://t.me/username
   - vk — ссылка https://vk.com/...
   - email, address
2. Изображения — объект IMG. Укажите свои URL.
3. Услуги — массив SERVICES. Цены утверждённые, менять нельзя (см. ТЗ).
4. Комплексы — BUNDLES, Галерея — GALLERY, Вопросы — FAQ.

## Подключение формы заявки
Форма готова к интеграции. Пока подключение не настроено — при отправке честно
показывается сообщение о том, что нужно связаться напрямую.

Чтобы подключить приём заявок, в каждом блоке формы укажите endpoint:
замените `data-hook=""` на `data-hook="https://ваш-сервис/путь"`.

Примеры интеграции: Telegram-бот, Google Sheets (Apps Script), CRM, сервисы форм.
Отправка идёт методом POST с JSON.
